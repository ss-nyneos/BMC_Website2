# BMC Bank website revamp

Homepage rebuild for Bombay Mercantile Co-operative Bank Ltd., built from the
supplied design specification.

React 18 · TypeScript · Tailwind CSS 3 · Vite. No other runtime dependency.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check, then bundle to dist/
npm run preview    # serve the production build
npm run typecheck
```

## Layout

```
src/
  assets/      icons, bullet marks and the logo, all inline SVG
  components/
    layout/    Container, Section, SplitPanel
    nav/       UtilityBar, Navbar, NavDropdown, MobileDrawer, DarkModeToggle
    ui/        the component library from spec section 6
    sections/  one file per homepage section, in page order
  data/        all copy, rates, navigation and notices
  hooks/       theme, media queries, scroll progress, focus trap, body lock
  types/       shared TypeScript contracts
  styles/      globals.css: token definitions and the reduced-motion rule
```

Copy and content live in `src/data`. Rates, navigation and notices can be edited
there without touching a component.

## Navigation

`src/data/nav.ts` holds two structures, deliberately separate:

- **`primaryNav`** is the bank's own nine entries, in the bank's own order, as
  they appear on the live site. Two of them open a dropdown. This drives both
  the desktop strip and the mobile drawer, so the two always agree.
- **`footerGroups`** is the grouped index of every destination. The strip is
  shallow, so the footer is the only place the whole site is reachable at once.

Nine entries do not fit on one row beside a logo and a call to action, so the
header is two rows: identity and the primary action above, the navigation strip
below. Below the `xl` breakpoint the strip is replaced by the drawer.

## Before this goes live

Marked in the code at each site:

- `src/data/notices.ts`, `src/data/branches.ts`: wire to the real archive and
  branch list. Branch counts are intentionally absent rather than invented.
- `src/data/firsts.ts`: the leadership quote is attributed to an office, not a
  person. Replace with a real named spokesperson and photograph.
- `src/components/ui/AppBadges.tsx`: replace the store search URLs with the two
  direct listing URLs, and the redrawn glyphs with Apple's and Google's official
  badge artwork.
- `src/components/sections/AppDownload.tsx`: the QR is generated by a
  third-party service. Generate and self-host it.
- `src/components/sections/EnquiryForm.tsx`: `onSubmit` currently resolves a
  timer. Point it at the bank's enquiry endpoint.
- Photography is stock, used to prove the layout. Swap for the bank's own
  branch and customer photographs, and rewrite the alt text to match.
